# power-bi-sales-analysis
Sales performance analysis using Power BI.

 Project Overview

This project analyzes sales performance using Microsoft Power BI. The goal is to turn sales data into useful insights that support business decision-making.

Objectives

* Analyze overall sales performance.
* Identify trends and patterns in the data.
* Compare performance across relevant categories.
* Present key findings through an interactive dashboard.

Tools Used

* Microsoft Power BI
* Power Query for data cleaning and transformation,
* DAX for calculations,

Key Performance Indicators (KPIs)
total sales
total order
total unit sold
average order value
